# 检索调优与实验顺序

## 先建立可信基线

历史 `backend/data/eval/results/eval_20261124_210335.json` 记录 20 题检索率 0.95、引用率 0.40、回答率 1.00、错误率 0.00。旧评分把答案关键词算入检索命中，并只检查引用标号，不能视为当前准确率基线。

此前自动补 [1] 的做法已移除；标号补齐不证明原文支持。原有 5 题冒烟通过也不等于全量通过。新口径见 `EVALUATION.md`。

## 本批先修程序问题

- 保护完整人名，避免别名连锁替换；区分指代消解、歧义和检索扩词。
- 原问题与改写一致时复用向量和召回；同一请求内去重 BM25，避免相同通道重复投票。
- 执行业务 prompt 的估算预算，保持原文、入选证据、引用编号和返回 hits 对齐。
- 检索评分不使用生成答案；引用范围有效与语义支持分开。
- 分别观察生成、全链路和首字耗时。

程序回归与页面交互通过，不构成真实模型效果已提高的证据。

## 后续参数实验

稳定后一次只改一项，保存数据集、代码、模型、索引版本及原始结果：

| 实验 | 观察重点 |
| --- | --- |
| 候选数从 16 调到 24 | 漏召回、重排耗时与费用。 |
| 最终 Top-K 从 4 调到 6 | 有效证据、噪声和预算裁剪。 |
| 调整相关性阈值 | 同时检查可答与无答案题，不能只看回答更多。 |
| overlap 从 64 字调到 96 字 | 跨句证据、重复片段和索引成本；需要重新索引。 |

章节偏移样例先人工核对证据，不能为追求现有标签命中直接加章节权重。切片参数单位是字符，不是精确 token。

真实实验产生 API 费用，切片实验还可能重建索引；本批未执行这些实验。先取得修正后的全量基线，再选择参数实验。
