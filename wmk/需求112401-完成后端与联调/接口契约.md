# 西游问典 · 后端接口契约（v0.1）

> 供前端联调使用。后端默认基址：`http://127.0.0.1:8010/api/v1`
> 流式问答：`POST /chat/stream`，`Content-Type: application/json`，响应 `text/event-stream`。
> 说明：当前后端实现与本文档同步维护；字段命名以后端 `backend/app/schemas/` 下 Pydantic 模型为准。

## 通用约定

- **协议**：HTTP/JSON；除流式问答外均为 JSON。
- **编码**：UTF-8。
- **时间**：ISO 8601 字符串，例如 `2026-11-24T10:20:30+08:00`。
- **金额**：人民币，`cost` 为浮点数（元），`formatCost` 前端显示规则可沿用 mock：`0 -> ¥0`，否则 `¥{cost.toFixed(6)}`。
- **错误响应**：
  ```json
  {
    "code": "bad_request",
    "message": "人类可读错误",
    "detail": {}
  }
  ```
- **CORS**：允许 `http://127.0.0.1:5180`、`http://localhost:5180`、`http://127.0.0.1:3333`。

## 数据模型（核心）

### `CostBreakdown`
```json
{
  "amount": 0.000128,
  "currency": "CNY",
  "usage": {
    "input_tokens": 120,
    "output_tokens": 0,
    "total_tokens": 120
  },
  "unit_price": {
    "input_per_1k": 0.0007,
    "output_per_1k": 0.002
  },
  "usage_known": true,
  "note": ""
}
```
- `usage_known=false` 时，`usage` 字段可省略或置空，前端应显示“用量未知”。

### `PipelineStage`
对应前端 `stages[step.key]` 与 `PIPELINE_STEPS`：
```json
{
  "key": "embed",
  "status": "done",
  "ms": 48,
  "cost": 0.000084,
  "summary": "84 tokens · ¥0.000084",
  "detail": {}
}
```
- `status` 枚举：`idle | running | done | skipped | stopped`
- 七个阶段固定顺序：
  1. `rewrite` 查询改写
  2. `embed` 向量化
  3. `retrieve` 稠密 + 稀疏召回
  4. `fusion` 融合
  5. `rerank` 重排
  6. `assemble` 组装上下文
  7. `generate` 生成

### `RetrievalHit`（对齐前端 `hits`）
```json
{
  "id": "c-000123",
  "rank": 1,
  "score": 0.812,
  "scoreText": "0.812",
  "chapter": 1,
  "chunk": {
    "id": "c-000123",
    "chapter": 1,
    "chapterTitle": "第 1 回",
    "text": "原文片段……",
    "tokens": 186,
    "source": "西游记.txt"
  }
}
```

### `ChatSettings`（对齐前端 `settings`）
```json
{
  "topK": 4,
  "threshold": 0.35,
  "rerank": true,
  "temperature": 0.3,
  "model": "qwen-plus",
  "chunkSize": 512,
  "chunkOverlap": 64,
  "streaming": true,
  "systemPrompt": "你是《西游记》阅读助手……"
}
```

## 3. 入库费用估算与索引任务

> 全文付费入库**不会自动执行**。必须先调用估算接口，再由前端显式确认后创建任务。

### `POST /knowledge/index/estimate`
**请求**
```json
{
  "mode": "full",
  "sample_chunks": 32,
  "chunk_size": 512,
  "chunk_overlap": 64
}
```
- `mode`：`sample | full`
- `sample_chunks`：仅在 `mode=sample` 时生效，默认 `32`，用于“少量付费样本验证”。

**响应 200**
```json
{
  "estimate_id": "est_20261124_001",
  "mode": "full",
  "chunk_total": 1286,
  "chapter_total": 100,
  "embedding_tokens_estimated": 920000,
  "cost": {
    "amount": 0.644,
    "currency": "CNY",
    "usage_known": true,
    "note": "按 text-embedding-v4 单价估算"
  },
  "requires_confirmation": true,
  "message": "全文入库预估 ¥0.644000，请确认后再创建索引任务"
}
```

### `POST /knowledge/index/tasks`
**请求**
```json
{
  "estimate_id": "est_20261124_001",
  "confirm": true,
  "mode": "full"
}
```
- `confirm=false` 或缺失 `estimate_id`：返回 `400`，不创建任务。
- `mode=full` 且未确认：返回 `409`，并保留估算结果。

**响应 202**
```json
{
  "task_id": "idx_20261124_001",
  "status": "queued",
  "mode": "full",
  "progress": 0,
  "message": "索引任务已创建"
}
```

### `GET /knowledge/index/tasks/{task_id}`
**响应 200**
```json
{
  "task_id": "idx_20261124_001",
  "status": "running",
  "mode": "full",
  "progress": 42,
  "processed_chunks": 540,
  "total_chunks": 1286,
  "current_stage": "embedding",
  "message": "正在写入 Milvus……",
  "cost": {
    "amount": 0.271,
    "currency": "CNY",
    "usage_known": true
  },
  "started_at": "2026-11-24T12:40:01+08:00",
  "finished_at": null,
  "error": null,
  "result_collection": null
}
```
- `status`：`queued | running | succeeded | failed | cancelled`
- 成功后会写入 `result_collection`，并由后端切换 active collection；失败时 **不切换**，旧索引继续服务。

### `GET /knowledge/index/tasks/current`
返回最新一个 `queued/running` 任务；没有则 `null`。

## 4. 流式问答（SSE）

### `POST /chat/stream`
**请求**
```json
{
  "question": "孙悟空是怎么诞生的？",
  "history": [
    { "role": "user", "content": "这本书讲什么？" },
    { "role": "assistant", "content": "……" }
  ],
  "settings": {
    "topK": 4,
    "threshold": 0.35,
    "rerank": true,
    "temperature": 0.3,
    "model": "qwen-plus",
    "streaming": true,
    "systemPrompt": "你是《西游记》阅读助手……"
  }
}
```

**响应**：`text/event-stream`

每个事件格式：
```
event: stage
data: {"key":"rewrite","status":"done","ms":12,"cost":0,"summary":"已补充关键词","detail":{...}}

event: hits
data: {"hits":[...]}

event: token
data: {"text":"根据"}

event: answer
data: {"text":"……","hits":[...],"meta":{"latency":1820,"tokens":236,"cost":0.00091,"followUps":["……"]}}

event: error
data: {"message":"……"}

event: done
data: {"ok":true}
```

#### `rewrite.detail` 建议字段
```json
{
  "original": "他后来叫什么？",
  "rewritten": "美猴王后来又称什么法号？ 孙悟空 唐僧徒弟",
  "reason": "结合上下文补全人物与原著关键词",
  "method": "上下文增强改写"
}
```

#### `retrieve.detail` 建议字段（对齐前端右侧链路面板）
```json
{
  "indexSize": 1286,
  "dense": { "metric": "余弦相似度", "items": [/*topN*/] },
  "sparse": { "metric": "BM25", "items": [/*topN*/] }
}
```

#### `fusion.detail`
```json
{ "method": "RRF", "k": 60, "items": [/* fused rows */] }
```

#### `rerank.detail`
```json
{
  "skipped": false,
  "model": "qwen3-rerank",
  "threshold": 0.35,
  "dropped": 2,
  "tokens": 980,
  "price": "¥0.0008 / 千 tokens",
  "items": []
}
```

#### `assemble.detail`
```json
{
  "ids": ["c-000123", "c-000045"],
  "tokens": 812,
  "budget": 2048,
  "prompt": "……"
}
```

#### `generate.detail`
```json
{
  "model": "qwen-plus",
  "temperature": 0.3,
  "streaming": true,
  "inputTokens": 812,
  "outputTokens": 236,
  "priceIn": "¥0.0008 / 千 tokens",
  "priceOut": "¥0.0020 / 千 tokens"
}
```

## 5. 前端对接建议

1. 用 `fetch` + `ReadableStream` 或 `EventSource` 替代品解析 SSE（`POST` 场景建议 `fetch`）。
2. 将 `event: stage` 直接 `Object.assign(stages[key], patch)`，字段与 mock 保持一致。
3. `event: hits` 更新右侧召回卡片；`event: token` 追加答案文本；`event: answer` 写最终 meta（latency/tokens/cost/followUps）。
4. 左侧“重新索引”按钮流程：
   - `POST /knowledge/index/estimate`
   - 弹窗展示费用 → 用户确认
   - `POST /knowledge/index/tasks`
   - 轮询 `GET /knowledge/index/tasks/{task_id}` 更新进度条
5. Vite 代理建议：
   ```js
   server: { proxy: { '/api': 'http://127.0.0.1:8010' } }
   ```
